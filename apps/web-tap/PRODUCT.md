# Tap workspace

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React 19, TypeScript and Vite 7; CLI-Manager's existing Cookie/WebSocket/operation protocol and authoritative native PTY.

## Users

CLI-Manager users continuing a registered local/WSL project from their phone or desktop browser.

## Product Purpose

Offer Tap-Code's session-oriented workspace as an independent Web choice. Users send tasks to a real CLI, operate its native menus and read its real conversation history.

## Capabilities and Constraints

Classic Web remains available. The host owns projects, paths, processes and approvals. The client never guesses a CLI session from a directory or launches a structured conversation behind the terminal. Unsupported capabilities are explicit. Native execution requires an online device bridge.

## Brand Commitments

The user explicitly requested the established Tap-Code Web design and its interaction optimizations. Preserve folder navigation, a dark native terminal, quiet light/dark workspace, bottom composition, two-row keys and phone-first focus/gesture behavior. Both Chinese and English are required by upstream.

## Product Principles

Native CLI remains authoritative. Preserve drafts and reading position. Distinguish connection state from process state. Destructive actions are deliberate. Independent clients share execution contracts, not UI state.
