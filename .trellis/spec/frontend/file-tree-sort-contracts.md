# 文件树排序契约

## 范围

桌面 FileExplorerSidebar 的侧栏与嵌入面板、shared/lib/fileTreeSort.ts 和 shared/preferences/fileTreeSortPreference.ts。独立 apps/web 不在此契约内。

## 排序

- Settings.fileTreeSort 是唯一持久化真值，字段为 key（name/date）与 direction（ascending/descending）。默认名称升序；切换到日期默认降序。重复选择当前维度不覆盖用户方向。
- 每层目录先于文件，升降序不能反转目录优先级。名称采用忽略大小写的自然排序；日期采用 modifiedMs。
- 仅有限且非负的数值时间有效，0 是有效时间；缺失、NaN、无穷或负值均在同类型内后置。同时间按名称稳定排序。
- 排序为原始树的只读投影；所有已加载 children 递归采用当前偏好，未加载目录保持按需读取。搜索结果、选择、路径、编辑器缓冲区与展开状态不被排序修改。

## 更新与错误

- 菜单提交单项变更，不提交来自旧渲染的完整设置快照。
- 所有文件面板共用一个串行更新器；每次出队时读取当前 Settings，再合并并持久化，防止连续选择相互覆盖。
- 队列恢复仅保证后续任务继续执行，当前保存失败必须传播给调用者；菜单显示失败且允许重试，不宣称保存成功。
- 通用设置更新入口仅为 fileTreeSort 增加规范化，避免备份恢复在下一次 load 前发布非法排序状态；其他设置更新行为保持不变。
- 保存期间禁用重复操作并显示状态；方向按钮与日期方向文案同步，两个单选分组和键盘导航可访问。

## 回归

用例位于 scripts/fileTreeSort.test.mjs，覆盖四种排序、目录优先、异常/相同时间、时间 0、递归不可变、默认方向、连续更新、写失败后重试、搜索分流和中英文键。实际界面、慢存储、重启恢复、本地/WSL/SSH 由人工验收；不能把用例存在或静态检查当作运行通过。
