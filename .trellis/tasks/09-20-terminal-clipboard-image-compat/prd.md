# 跨平台终端剪贴板图片兼容与容量提升

用户已批准实施，版本 V1.4.1。Snipaste 截图不能直接粘贴，经过微信粘贴并重新复制后可用；无远端剪贴板现场，不能宣称根因已在用户环境复现。

## 要求和验收
- 本机/WSL 终端图片附件提高到 20 MiB、40,000,000 像素；SSH 通用上传保持 20 MiB。
- Windows 按 PNG、DIBV5、DIB（含系统从 Bitmap 合成）多表示尝试，单种转换失败不能阻断其他合法表示。
- macOS 支持 PNG、TIFF 及 Finder 文件 URL；Linux 保留既有插件读取。
- 浏览器图片识别覆盖 items/files、空 MIME，通过后端实际解码验证；路径复制、文字不被误吞。
- Ctrl+V、右键、Alt+V 图片路径共用后端标准化，SSH 仅发送上传后的远端路径，WSL 继续格式转换。
- 明确提示读取/解码/超限错误，有限重试占用；不改变剪贴板内容，不关闭图片安全检查。
- 定向测试和架构、tsc、cargo check 通过。macOS 无实机时如实标注。

## 范围外
文件预览 5 MiB/12M、文件树导入 64 MiB、旧 SSH Agent 协议 5 MiB/12M 不变；不支持所有私有格式、HEIC/HEIF 或任意虚拟文件协议。
