# 技术设计

## 根因

Pi 模板对 `ui_prompt_start` 仅发送普通 `Notification`，结束时只恢复工作心跳；四色灯又明确排除没有 `pendingAction` 的普通 attention。因此问题在等待状态的生产与传输缺失，不是黄灯颜色或通知开关。

## 关键决策

- 用户补充的结构约束：以外挂和既有 fork 独有文件为主，上游只留字段透传与少量入口调用。不修改上游 `terminalStoreTypes.ts` / `terminal/state.ts`；专用事件标记、分发、校验和状态机归入独立文件。接入清单维护于 `pet-e/docs/pi-terminal-prompt.md`，共享 Hook 契约仅保留链接。

- 使用 Pi 公开 `ui_prompt_start` / `ui_prompt_end`，状态精度为 Pi 合并后的外层等待区间，不推断每个自绘控件的答案。
- 采用独立的只读等待字段，不复用 broker 的 `/open`。该入口会替换同会话的 Waiting 请求，借用它会误撤销真实审批；本次不修改 broker。
- 复用现有鉴权 Hook HTTP 与 daemon 广播，增加 Pi 专用 `DesktopPetEUiPrompt` 状态事件，不增加端口、请求回答接口或自动配置。
- 该专用事件不进入普通任务状态、第三方通知、handoff、Replay、toast、任务栏提醒或子任务分屏。daemon 仅广播，App 的通用 Hook 入口提前返回；宠物协调器独立接收。
- 等待区间按终端 Tab、Pi 会话、扩展实例、区间 ID 与单调序号关联；终端身份不匹配时不展示。
- 活跃区间每 5 秒续报，前端仅保留最近 30 秒有效的状态。结束立即上报；过期、缓存重播、迟到包、重复包和错误会话分别处理。续报不改变区间 ID/开始时间，不因此重绘宠物快照。
- 官方事件包括本扩展自己的界面也可提供只读状态；同会话以真实 `pendingAction` 的交互为优先，始终只有一条任务。这样无需用是否可代答来猜测其他嵌套 UI 是否仍打开。
- 心跳与状态显示分离：正式等待期间挂起工作心跳；等待结束、agent 仍活跃时立即报告继续工作，不凭普通工作心跳清理等待。
- 模板版本 8 → 9；仍以外部模板嵌入，已安装文件由用户更新应用后触发托管升级，不直接编辑安装副本。

## 数据与边界

专用 Hook 仍带 `tabId/source/event/sessionId/timestamp/remoteEventId`，新增 `terminalPrompt`：

- `instanceId`：Pi 扩展实例。
- `id`：等待区间 ID。
- `sequence`：实例内单调正整数，限制为 JavaScript 安全整数。
- `active`：是否仍等待。
- `kind`：`select/confirm/input/editor/custom`。
- `title`：可选且有长度上限，仅作为显示内容，始终转义。

Rust 拒绝非 Pi 来源、缺失身份、非法种类/序号/标题、SSH 伪装及在普通事件附带专用状态。普通事件的字段结构和行为不变。

前端独立 reducer 维护有界状态与结束游标，按发出时间剔除旧缓存，按实例/序号拒绝乱序。`SessionStart`、`Stop`、`StopFailure` 只在来源、会话及时间匹配时清理。工作心跳不是结束凭据。

快照的可选 `terminalPrompt` 字段只表达只读展示；不改变提交动作契约。不存在真实 pendingAction 时，渲染器显示“请在终端作答”，沿用已有打开会话按钮。

## 场景矩阵

| 场景 | 处理 |
|---|---|
| 单会话、多会话、跨 Workspan/分屏、非焦点窗口、托盘 | 用精确终端 ID，沿用已有定位/打开流程，不依赖当前焦点 |
| 本机/WSL、普通项目/Worktree | 复用已有 Hook 地址和身份，保留 WSL 字段 |
| 非 PTY / SSH / 无对应存活终端 | 不显示此本地 Pi 等待状态 |
| 通知或代答关闭、宠物开启 | 黄灯仍可显示，但不可提交答案 |
| 宠物关闭后重开 / 前端重连 | 活跃区间续报恢复；旧缓存不能延长已失效等待 |
| 终端退出 / Pi 会话重置 / daemon 重启 | 清理或不再展示；缺失结束事件由短租期回收 |
| 真实可回答问题与只读状态重叠 | 保留真实请求、提交中状态和仅一次计数 |
| 迟到开始、迟到结束、重复续报 | 游标/区间/时间隔离，不能撤销新状态或复活旧状态 |
| Pi 旧版本缺少官方事件 | 不猜测自绘等待；原有标准控件代答保持原样 |

## 风险与回退

- 新增跨层可选契约，需同时升级应用/daemon 与模板，运行验收由用户执行。
- Hook 中断超过 30 秒时，等待指示会暂时撤下，避免无期限假黄灯；有效续报恢复。
- 既有共享入口接近 2000 行，只加薄接线；验证/状态机进入独立文件，不扩展大型 broker。
- 可回退本次单独提交；不改变第三方插件、真实回答协议或已安装配置。
