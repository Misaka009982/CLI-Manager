# 历史索引内存优化

用户授权：新任务，沿用 1.4.3，验证后提交、缓存构建 NSIS，不推送。保留历史/统计数据、50,000 行回滚、低内存与 Codex 渲染设置，不关闭用户终端或修改真实配置。

证据：主进程工作集约 564–1354 MiB；历史 JSON 派生缓存 536 MiB。每 60 秒请求日志同步触发索引，索引快照/刷新/保存深拷贝完整统计向量，保存另造整份 JSON 字节，且先构造全部请求文档再筛选变化。

验收：索引快照共享不可变大统计，旧 JSON 兼容；流式读写与失败保护；仅变化文件构造请求文档；并发刷新不重复构建；统计/删除/不可访问来源不回归。临时数据回归和独立进程内存对比，明确未覆盖真实 GUI 的边界。
