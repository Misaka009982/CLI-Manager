# Design

全局 `terminalLayoutLocked` 偏好由 settingsStore 持久化，缺省/非法值归一为 false。终端 API 提供最新状态读取、带固定 toast id 的拦截提示和解锁动作，终端 store 的用户布局变更入口统一拦截；异步 splitTerminal 在创建前和布局提交前检查，取消时关闭新 PTY 并释放快照。

两类 Sortable 标签禁用拖动源，同时使用轻量指针观察器在超过既有启动距离时提示，每手势仅一次，pointerup/cancel/失焦/卸载清理。拖动回调与分隔线预览另检查最新状态，覆盖拖动中途锁定。

终端 API UI 模块提供右键项、空白区域菜单容器和小锁组件。顶层 Workspan 栏显示唯一锁标记；无可见顶层栏时由当前 Pane 栏显示。嵌套标签菜单保持既有菜单内容和皮肤。锁定偏好变更不重挂载终端。

锁定仅限制用户布局操作；自然会话生命周期/恢复不受影响。现有公共拖动阈值保持 3px。

影响工具目前无法解析相关 TSX/store 符号，风险 UNKNOWN；通过领域契约与限定引用检查补齐入口。重点风险为快捷键绕过、分屏异步竞态、嵌套菜单冒泡、无顶层栏时入口缺失。

## 验收反馈修正

- 通用 `ui-icon-action` 使用应用主题，不适合终端独立主题；小锁复用 `ui-terminal-tab-list-button`，toast 与其解锁动作保留应用默认通知样式，不设置终端主题配色覆盖。
- 两层 ContextMenu 存在事件归属耦合：标签主动 stopPropagation，空白区 trigger 排除带 tab/workspan 标识的目标，锁状态不改变标签菜单。初版单元测试仅渲染菜单项，未验证实际 DOM 事件；补充真实 Radix/DnD/生产标签与 CSS 的浏览器隔离测试。
- 菜单项移除图标，仅栏末的状态按钮显示锁图标。
