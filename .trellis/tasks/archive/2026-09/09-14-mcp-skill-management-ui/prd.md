# MCP 与 Skills 管理 UI 优化

## Goal

在不改变 MCP/Skills 数据模型、IPC 契约、保存时机、CLI 适配和外部文件保护规则的前提下，重做全局 MCP/Skills 管理页及项目级 MCP/Skills 策略弹框的视觉层级和交互密度，让资源状态更容易扫描、配置更容易编辑、原生配置预览更容易阅读。

版本记录目标：`V1.4.0`。

## Confirmed Facts

- 全局入口由 `SettingsModal` 挂载，MCP/Skills 页签占用设置页头部搜索替换区域；`GlobalExtensionsPage` 负责数据刷新，`GlobalMcpPanel` 与 `GlobalSkillsPanel` 负责列表。
- MCP 卡片、Skill 卡片和详情实例目前混用 Mantine `Card`，Skills 的来源、安装记录和操作收在卡片内的原生 `details` 中；当前视觉密度和 MCP/Skills 两个列表的行结构不一致。
- `McpEditorDialog` 当前使用 `Textarea` 展示格式化的单服务 `mcpServers` JSON；项目已有 `@monaco-editor/react`、`monaco-editor`、JSON worker 和 Monaco 本地化配置。
- `NativeMcpPanel` 当前需要先选择 CLI，再点击生成预览；结果只展示路径、名称集合和变更提示，没有使用已有 `McpProjectionPreview.content` 的格式化代码展示。
- `GithubSkillDialog` 和 `ExtensionImportDialog` 使用手写全屏遮罩与较多嵌套控件；项目级 `ProjectExtensionsDialog` 已有固定视口与独立滚动区，但信息层级、状态摘要和策略选择仍需收紧。
- 后端现有能力包括 `extensions_mcp_preview`、`extensions_mcp_native_preview`、Skill GitHub 预览/安装和项目策略读写；原生预览当前返回路径、指纹和名称集合，若要在同一预览中展示最终合并正文，需要给既有 `extensions_mcp_native_preview` 增加只读、脱敏的正文/格式字段，不新增命令或持久化字段。
- 相关契约要求：MCP 原生预览只读，显式保存仍是唯一写入入口；列表排序独立持久化；Skill 同名来源、外部安装、未知扫描状态和所有权语义必须保留；项目策略只保存当前 CLI 的继承/自定义策略。

## Requirements

### R1. 全局 MCP 列表

- 将现有大卡片改为紧凑、统一高度的资源行，减少上下留白和嵌套边框。
- 名称、server key、传输类型、来源、CLI 启用状态、拖动手柄、编辑和删除操作保持清晰分区；长名称和路径不得撑破布局。
- 保留现有排序、CLI 独立开关、待应用状态、保存 MCP 配置、刷新、添加和导入行为。

### R2. MCP 编辑器

- 添加/编辑 MCP 使用真正的 JSON 代码编辑器，支持语法高亮、格式化可读性、JSON 基本校验、滚动和键盘编辑。
- 保留当前单服务 `mcpServers` 结构、脱敏字段处理、隐藏 canonical 元数据、Rust 语义校验和底部固定操作区。
- 编辑器主题、字体和交互状态跟随应用主题/语言，失败时显示可定位的本地化错误，不泄露秘密或完整 IPC 错误。

### R3. MCP 配置预览

- 将“选择 CLI + 生成预览 + 查看结果”收敛为一个弹框内的直接预览体验，打开后无需再经过第二个操作层级才能看到内容。
- 预览内容复用现有原生预览计划的最终合并结果，按目标 CLI 显示脱敏 JSON/TOML 正文、格式徽章、资源数量、变更状态、脱敏说明和不兼容字段；新增字段只读返回，不复用写入调用。
- 预览只读，不改变待应用状态，不写入 native 文件；三个 CLI 的切换应在同一弹框内完成，并保持显式保存入口的职责。

### R4. GitHub Skill 安装弹框

- 重做弹框的标题区、来源输入区、扫描状态、候选列表、部署目标、同步方式和结果区，减少空白与重复边框。
- 未扫描时突出仓库/ref/子目录输入和扫描动作；扫描后突出候选选择、目标配置和安装动作，避免把两个阶段挤在同一层级。
- 保留固定 commit、多候选勾选、取消操作、目标 CLI/同步方式、部分失败、警告和本地化错误。

### R5. 全局 Skills 列表

- 列表行的基础视觉结构与 MCP 保持一致：名称和摘要在左，CLI 状态图标及操作在右，拖动手柄位于名称左侧。
- 默认行保持紧凑，只展示名称、摘要和必要状态；来源变体、外部路径、安装记录、备份恢复、高级部署等继续按需查看，但改为更清晰的详情面板/折叠层级。
- 保留同名来源变体选择、三 CLI 目标检查、外部安装保护、安装/卸载/恢复、扫描完整性语义和独立排序。

### R6. 项目 MCP 与 Skills 策略弹框

- 重做标题、项目/Worktree 身份、MCP/Skills 切换、能力/应用状态、继承/自定义策略、资源列表和有效集合预览的视觉层级。
- 资源列表和预览区继续独立滚动，弹框和底部操作在视口内稳定可见；不得引入外层滚动遮挡。
- MCP 与 Skills 使用一致的行组件和选中态；搜索、禁用态、不支持 CLI、SSH/未知 WSL 身份提示和保存边界均保留。

### R7. 国际化与可访问性

- 所有新增或修改的可见文案、按钮提示、aria-label、状态说明同时覆盖 `zh-CN` 与 `en-US`；不硬编码中英文。
- 图标按钮使用现有 Lucide/CLI 图标并提供 tooltip 或 aria-label；键盘用户可完成编辑、切换、选择、排序和关闭。
- 支持窄窗口、长名称/路径、浅色/深色主题，文本不得溢出或覆盖相邻内容。

## Acceptance Criteria

- [ ] 全局 MCP 与 Skills 列表在相同窗口宽度下采用一致的紧凑行密度；单行能清楚区分名称、摘要/来源、CLI 状态和操作，长文本可截断或换行且不破坏布局。
- [ ] 添加/编辑 MCP 打开 Monaco JSON 编辑器，能够输入有效单服务 JSON、显示 JSON 语法错误、保留脱敏字段约束，并完成现有保存链路。
- [ ] MCP 配置预览打开后在同一弹框内显示目标 CLI 的格式化脱敏 JSON/TOML 内容；切换 Claude/Codex/Grok 不需要打开第二个弹框，预览仍不写文件。
- [ ] GitHub Skill 弹框在输入、扫描、候选选择、安装中、部分失败和完成状态下均有稳定的布局与明确的主要操作；取消不会破坏已保存源包。
- [ ] Skills 行保留同名不同 hash 来源、外部/受管/异常安装及三 CLI 图标语义；快捷安装/卸载和高级详情行为不回归。
- [ ] 项目策略弹框在至少 768px 高度和窄宽度下底部按钮可见，资源列表/预览独立滚动，MCP 与 Skills 切换和保存策略保持原行为。
- [ ] 中英文切换后上述页面和弹框无缺失键、硬编码文案或英文环境下的 12 小时制时间回归。
- [x] `npx tsc --noEmit`、`npm run check:architecture -- --strict` 和受影响的定向测试通过；按项目规则记录人工桌面验收项，不启动 Tauri 桌面应用进行自动视觉验证。

## Scope Boundaries

- 不新增依赖、数据库表、迁移、Tauri command、IPC 请求参数或后端配置格式；允许在既有 `extensions_mcp_native_preview` 响应中增加只读、脱敏的预览字段，以满足格式化预览。
- 不改变 MCP canonical 数据、原生配置写入时机、revision/指纹保护、秘密脱敏、Skill 安装所有权和项目策略语义。
- 不在本次任务中引入市场搜索、Skill 自动更新、原生配置自动写入或新的 CLI 支持。

## Resolved Decisions

- MCP 配置预览采用同一弹框内的 CLI 页签，打开后默认直接加载第一个可用 CLI；不并排展示三个 CLI，以保留足够的代码阅读宽度。
- 全局 Skills 默认使用与 MCP 同密度的紧凑资源行；来源变体、安装记录和高级部署信息使用行内展开的详情区，不再打开第二层弹框。
- 原生 MCP 预览直接复用现有预览计划的脱敏最终正文；弹框打开后自动加载默认 CLI，切换 CLI 自动刷新，保留路径、指纹/变更状态和只读语义。

## Planning Status

产品范围与关键交互已收敛；剩余视觉尺寸、组件拆分和验证顺序记录在 `design.md` 与 `implement.md`，不再保留阻塞性问题。
