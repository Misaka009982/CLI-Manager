# 终端字体优先级与回退修复

## 目标
恢复用户自定义字体优先的终端呈现；仅在字体不可用或缺少字形时由后续字体补充。

## 背景
- b8c784d 在 generic monospace 之前强制插入 CJK 字体，导致中文变化，并可能在主字体缺失时接管英文和数字。
- src/features/terminal/api/terminalFontFamily.ts:53 是终端和相关预览的统一处理入口。
- src/features/settings/components/pages/ThemeSettingsPage.tsx:1038 会保存已追加的字体串，单纯回退代码不一定消除影响。
- 用户已批准独立创建任务，沿用 V1.4.1；字体修复与外部终端程序选择分别交付。

## 要求
- R1：保留用户字体选择，已安装且含目标字形的字体不得被内置回退覆盖。
- R2：字体不可用/字形缺失时有稳定回退；中文回退不得将英文/数字变为比例字体。
- R3：兼容历史自动追加配置，不按字体名称粗暴删除用户主动选择。
- R4：终端与字体/状态栏预览一致；不改变应用 UI 字体或外部终端软件字体。

## 验收
- 默认、单个自定义、多个自定义、仅 monospace、字体缺失、含中文/空格/逗号的字体名有行为测试。
- 可确认完整自动尾部指纹的历史配置恢复用户前缀；用户显式选择中文字体保留。无法确认来源的手工混合配置保留，不冒险删除。
- 用户配置保存不再混入内部运行时回退栈。
- 中英文文案（如有）、TypeScript、定向测试、严格架构检查通过；V1.4.1 两份变更记录更新。

## 范围外
不改变 UI 字体，不提供字体安装，不凭主观外观判断字体损坏。
