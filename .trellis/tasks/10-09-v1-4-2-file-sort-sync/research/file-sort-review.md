## 已核对的不变量

- 目录比较先于维度比较，因此升降序不会把目录排到文件之后。
- 排序使用复制数组，并对已加载 children 递归；原树和文件操作状态仍由原 store 持有。
- visibleRows 在文件搜索时使用 searchResults；代码搜索另有独立分支。
- 原生/WSL 文件命令与 SSH Agent 均提供 modifiedMs；SSH 转换保留该字段。
- 偏好字段有默认值、加载迁移和备份分类；popover 新 prop 可选，不改变默认挂载点。
