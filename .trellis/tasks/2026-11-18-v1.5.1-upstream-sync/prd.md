## 范围边界

- 不纳入正式标签之后的 `ebcb4537`，包括其中的历史页面信息栏隐藏修复；该差异明确留给后续同步。

## 重点场景

- 本机 PowerShell/CMD/Pwsh 与 WSL，多窗口、分屏、Workspan、后台/托盘；SSH 沿用原能力边界。
- Pi 失败后新会话、连续切换和 reload、迟到 HTTP 回调；明确空闲不复活旧红蓝历史，真实待答始终优先。
- 宠物E与原宠物互斥、开关关闭、旧折叠值、设置页重新打开、中英文及新旧主题。
- 文件树慢 Git 查询、项目/Worktree/SSH 上下文切换；排序偏好不影响首屏可达或搜索次序。
- 便携包默认与自定义生产者、空格路径、盘符大小写、8.3 别名、过期 Cargo 资源副本、缺失/损坏 Electron，以及重复打包。
- 新信息栏复用明确空闲消费者；内存优化的进程判定不得扩大到宠物或普通用户终端。

## 完成标准

固定上游提交成为集成结果祖先，交叉接点无明显悬空类型或注册，版本与脚本输出契约一致，fork 独有文件保留。
静态证据、未运行验收和残余风险写入 `verification.md`；提交推送按本轮确认方式执行，未授权时保持本地。
静态完成不等于构建、发布或运行验收通过。
